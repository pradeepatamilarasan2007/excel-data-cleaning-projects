           EXCEL DATA CLEANING PROJECT
This project demonstrates cleaning a raw Excel dataset to make if ready for analysis. The dataset contains messy data with missing values,inconsistent formatting, and extra spaces.
The Excel file includes two sheets: "raw data", which is the original unclean dataset,and "data processing",which contains the cleaned dataset.
And I created a new column (Full name) by combining first and last name.
Performed data cleaning by trimming extra spaces,handling missing values,standardizing text and validating numeric data.
This project highlights the process of preparing a clean dataset suitable for analysis and reporting.
